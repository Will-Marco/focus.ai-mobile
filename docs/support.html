Getting started

Do I have to register?

No. The app works fully without an account — create habits, run sessions, read your statistics, and both Focus Modes are available. An account is only for moving your data to another device and joining focus rooms.

The verification code never arrived

The code comes through a Telegram bot. Check that Telegram is installed and that you entered the number in international format — +998…

Focus Modes

I put the phone down but “Away” did not start

This mode relies on the motion sensor. Usually it is one of these:

  • No session is running — Away only works during a session
  • The phone is in your hand or moving — it needs to lie still
  • You picked it up too quickly — there is a short wait before it triggers, so it does not fire by accident
  • You are testing on an emulator — there is no sensor there, use a real phone

Do Not Disturb is not switching on

On Android this needs a separate system permission, requested the first time you open Focus Clock. Apple does not expose this to apps on iOS, so only in-app silence works there.

Data and syncing

The session time looks wrong

The timer runs on real timestamps, so it stays correct even if you close the app or the phone sleeps. If you still see a discrepancy, write to us and mention your phone model.

My data is missing on my second device

Syncing only works with an account. Check that both devices are signed in to the same one and have internet. You can also run it by hand with Sync on the Profile screen.

I want my account deleted

Write to the address above — we remove it within 30 days. Uninstalling the app clears the data held on your phone.
