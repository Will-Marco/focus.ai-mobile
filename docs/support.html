Bu rejim telefonning harakat sensoriga tayanadi. Tekshiring:

  • Sessiya faol bo‘lishi kerak — Away faqat sessiya davomida ishlaydi

Frequently asked questions

Do I need an account to use the app?

No. The app is fully functional in guest mode — creating habits, running sessions, statistics and Focus Modes all work without internet. An account is only needed for cross-device sync and the group features.

“Away” mode is not triggering

This mode relies on the motion sensor. Check that:

  • A session is running — Away only works during a session
  • The phone lies steadily face-down; it deliberately will not trigger while held in hand or moving
  • You wait a few seconds — there is a short hold window to prevent false triggers
  • You are on a real device — emulators have no motion sensor

Do Not Disturb is not turning on

On Android this requires a separate system permission, requested the first time you enter Focus Clock. On iOS, Apple does not expose this capability to apps, so only in-app silence is available there.

Session time looks wrong

The timer is based on real timestamps, so time stays correct even if the app is closed or the phone sleeps. If you still see a discrepancy, write to us and mention your device model.

My data is not appearing on another device

Sync only works when signed in. Check that both devices use the same account and have internet. You can also trigger it manually with the Sync action on the Profile screen.

I did not receive the verification code

The code is delivered through a Telegram bot. Check that Telegram is installed and that you entered the number in international format (e.g. +998…).

I want to delete my account and data

Write to the address above — requests are handled within 30 days. Uninstalling the app removes the local data on your device.
